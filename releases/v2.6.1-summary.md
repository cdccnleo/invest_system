### 3.1 Daemon/锁 (3 PIT) — fcntl.flock + .pyc 固化

#### PIT #111 (6/14 20:43) — schedule_runner 9h 僵尸 (commit `bd6c883`)

**实战触发**: 6/14 20:43 查 schedule_runner 旧进程 364446, ELAPSED 9h+, PPID=1, log 仍写但 cron 全跳过. `tail -f logs/schedule_runner.log` 没新内容.

**根因**: fcntl.flock 持锁 daemon, **lock 文件被外部 unlink 后 inode 引用仍被进程持有** — `ls -l logs/.schedule_runner.lock` 显示文件已被删 (`No such file`), 但 `lsof -p 364446` 实战 inode 仍被持有. 进程在 `fcntl.flock` syscall 上 `wait_woken`, 永远不返回, 但 scheduler.add_job 仍认为它在跑 (持锁).

**修复**: 3 步
1. `lsof -p PID | grep .lock` 找 lock fd
2. `kill -TERM PID` + sleep 5
3. watchdog 检测 + 自动启新 schedule_runner (新 fcntl.flock(INITIAL) 实战成功)

**实战数据**:
- 364446 实战 9h 全跳过 cron (36 个 job 全 miss)
- 重启后新 schedule_runner 449203 实战 36 job 全 schedule, 3min 内 cron_task_metrics 写 4 行 ✅

**防御**: 加 `lsof` 检查 + 进程 ELAPSED 监控 + watchdog 检测 `持锁 PID 是孤儿` (PIT #111 实战 + V2.7.1 文档化)

**实战新铁律**: **任何 fcntl.flock 持锁 daemon 实战前必查 `lsof -p PID`**. 锁文件 unlink 不等于持锁进程死亡.

#### 模板 4: dict.get(key, default) None 不覆盖 (PIT #117)

**症状**: 实战中 `'>' not supported between NoneType and int` 或 `unsupported format string passed to NoneType.__format__`

**实战复现**:
```python
>>> q = {"close": None, "open": 10.0}
>>> q.get("close", 0)  # 当 key 存在值 None 时, 默认值 0 不生效
None
>>> q.get("close", 0) > 0
TypeError: '>' not supported between instances of 'NoneType' and 'int'
>>> f"{q.get('close', 0):.2f}"  # f-string 同样 None
TypeError: unsupported format string passed to NoneType.__format__
```

**修复**:
```python
def _safe_num(v, default=0):
    """PIT #117: dict.get(key, default) 当 key 存在值 None 时, 默认值不生效"""
    if v is None:
        return default
    try:
        return float(v) if isinstance(v, (int, float, str)) else default
    except (TypeError, ValueError):
        return default

>>> _safe_num(q.get("close"))  # 不管 None 还是数字都返 0
0
>>> _safe_num(q.get("close")) > 0
False
```

**6 形态反模式** (实战新铁律): ① 比较 `>` ② 加减 ③ 浮点 ④ if-while ⑤ return ⑥ **f-string**

**跨项目铁律**: **`dict.get(key, default_value)` 当 key 存在值 None 时, 默认值不生效**. 必用 `_safe_num(v, default=0)` 兜底 None
